# 문자열 덧셈 계산기

## 🧩 목표

- 입력 문자열에서 숫자를 추출하여 합을 계산한다.
- 기본 구분자(`,`, `:`)와 **커스텀 구분자**(`"//{구분자}\n"`)를 지원한다.
- 명세에 맞는 **출력 형식**을 지키고, 예외 시 `IllegalArgumentException`을 발생시킨다.

---

## ✅ 기능 목록 (To-Do)

### 1. 입력 및 기본 동작

- [ ] 프로그램 시작 시 안내 문구 출력: `덧셈할 문자열을 입력해 주세요.`
- [ ] 입력이 `null` 또는 공백 문자열이면 결과 `0`을 반환한다.
- [ ] 결과는 `결과 : {합}` 형식으로 출력한다. (공백/콜론/순서 엄수)

---

### 2. 구분자 처리

- [ ] 기본 구분자(쉼표 `,`, 콜론 `:`)로 분리된 숫자를 합산한다.  
  예시
    - `"" → 0`
    - `"1,2" → 3`
    - `"1,2:3" → 6`
- [ ] 커스텀 구분자를 추가할 수 있다. 입력이 `"//{구분자}\n{숫자들}"` 형식인 경우 `{구분자}`를 구분자로 추가한다.  
  예시
    - `"//;\n1;2;3" → 6`
- [ ] 커스텀 구분자 형식이 올바르지 않으면 `IllegalArgumentException`을 던진다.  
  (예: `"//"` 이후 개행 미존재, 구분자 비어 있음 등)

---

### 3. 토큰 검증/파싱

- [ ] 분리된 각 토큰이 **숫자인지** 검증한다. 숫자가 아니면 `IllegalArgumentException`.
- [ ] 양수가 아닌 값이 포함되면 `IllegalArgumentException`.
- [ ] 연속 구분자 등으로 인한 **빈 토큰**(예: `"1,,2"`)이 발생하면 `IllegalArgumentException`.
- [ ] 정상 토큰을 정수로 파싱하여 누적 합산한다.

---

### 4. 구조/설계

- [ ] `Application.main()`에서 입력/출력 흐름을 담당한다.
- [ ] 계산 로직을 `StringAddCalculator.add(String input)`으로 분리한다.
- [ ] 구분자 파싱 로직을 별도 메서드/클래스로 추출한다. (가독성/테스트 용이성)

---

### 5. 예외 및 종료 정책

- [ ] 모든 **잘못된 입력은 `IllegalArgumentException`** 발생 후 애플리케이션 종료  
  (비정상 종료 코드 사용 금지, `System.exit()` 금지)
- [ ] 예외 메시지는 디버깅에 충분한 정보를 제공하되 출력 형식 요구사항과 충돌하지 않도록 한다.
